# LazerTrap

Плагин-ловушка "лазер" для зомби-режима на CS2 (CounterStrikeSharp), в духе классических
zombie-мод ловушек из CS 1.6: статичный луч между двумя точками, который наносит урон
и отбрасывает зомби при пересечении, не задевая живых (обычных игроков).

## Важное допущение

Плагин **не завязан** ни на какой конкретный зомби-фреймворк — он сам определяет
"зомби" по игровой команде (`TeamNum`). По умолчанию зомби = T (Terrorist, 2),
люди = CT (3). Если у вас наоборот — поменяйте `zombie_team` на `3` в конфиге.

Если вы используете отдельный зомби-плагин со своим API "IsZombie/IsHuman"
(например порт Zombie:Reloaded/ZombiePlague под CS2) — скажите, какой именно,
и я перепишу проверку под его API вместо `TeamNum`, это будет точнее (учтёт
неуязвимость на респауне, nemesis/boss-классы и т.д.)

## Сборка

Как и в остальных ваших плагинах — нужен .NET SDK с `CounterStrikeSharp.API` 1.0.371:

```
dotnet publish -c Release
```

Либо соберите через GitHub Actions, как вы уже делали для BlockSpectate.

## Установка

1. Скопировать собранную папку `LazerTrap` на сервер:
   ```
   csgo/addons/counterstrikesharp/plugins/LazerTrap/
   ```
2. Перезапустить карту/сервер или `css_plugins load LazerTrap`.
3. Конфиг создастся автоматически:
   ```
   csgo/addons/counterstrikesharp/configs/plugins/LazerTrap/LazerTrap.json
   ```

## Расстановка ловушек (без trace, просто встать в точку)

| Команда | Действие |
| --- | --- |
| `css_lazertrap_a` | Отметить точку A на месте, где стоит админ |
| `css_lazertrap_b` | Отметить точку B → создаётся луч между A и B |
| `css_lazertrap_undo` | Удалить последнюю созданную ловушку |
| `css_lazertrap_clear` | Убрать все ловушки на карте (только в памяти) |
| `css_lazertrap_save` | Сохранить текущие ловушки в `traps.json` для этой карты |
| `css_lazertrap_list` | Показать, сколько ловушек активно |

Требуется флаг `@css/root` (меняется в конфиге `admin_flag`).

Рабочий цикл: встали на точку A → `css_lazertrap_a` → перешли на точку B →
`css_lazertrap_b` (луч появляется сразу, можно проверить визуально) →
`css_lazertrap_save`. Ловушки хранятся в `traps.json` по имени карты и
подгружаются автоматически при следующей загрузке той же карты.

## Лазер для всех игроков (во время раунда)

Это отдельная механика от расстановки админом — временный лазер, который **любой игрок**
(не только админ) может поставить сам, без прав.

| Команда | Действие |
| --- | --- |
| `css_laser` / `css_lazer` | Поставить временный луч прямо перед собой (в направлении взгляда, по горизонтали) |

Как это работает:
- Луч ставится мгновенно на фиксированную длину (`player_place_length`) от игрока вперёд.
- Живёт `player_place_duration` секунд, потом сам исчезает.
- У каждого игрока свой кулдаун `player_place_cooldown` — пока не истёк, команда просто скажет, сколько осталось ждать.
- По умолчанию ставить могут только "люди" (не-зомби сторона) — меняется через `player_place_humans_only: false`, если нужно разрешить всем без разбора команды.
- Урон/отброс от такого лазера работает точно так же, как от админских — по тем же настройкам `damage`, `hit_radius`, `knockback_force` и т.д.

Привязать на клавишу игрок может сам через игровую консоль:
```
bind "g" "css_laser"
```

## Конфиг (`LazerTrap.json`)

| Параметр | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `zombie_team` | int | `2` | Какая команда считается зомби (2=T, 3=CT) |
| `damage` | float | `15` | Урон за одно срабатывание |
| `damage_interval` | float | `0.5` | Кулдаун урона на одного игрока, сек |
| `knockback_force` | float | `350` | Сила отбрасывания от луча |
| `hit_radius` | float | `18` | Радиус срабатывания вокруг луча (юниты) |
| `beam_width` | float | `1.2` | Толщина визуального луча |
| `beam_color` | string | `"255 40 40"` | Цвет луча, `R G B` |
| `hurt_sound` | string | путь к звуку | Звук при попадании |
| `hurt_humans` | bool | `false` | Бьёт ли луч живых игроков тоже |
| `admin_flag` | string | `"@css/root"` | Флаг для админских команд расстановки |
| `player_place_enabled` | bool | `true` | Включает лазер для всех игроков (`css_laser`) |
| `player_place_cmd` | string | `"css_laser,css_lazer"` | Команды для игрока |
| `player_place_cooldown` | float | `20` | Кулдаун между постановками, сек |
| `player_place_length` | float | `250` | Длина луча от игрока вперёд |
| `player_place_duration` | float | `15` | Сколько живёт временный лазер, сек |
| `player_place_humans_only` | bool | `true` | Ставить могут только не-зомби |

## Ограничения текущей версии

- Урон применяется напрямую через `m_iHealth`, а не через `CTakeDamageInfo` —
  убийство засчитывается как suicide (без килфида "убит лазером"). Если важен
  красивый килфид — можно доработать через нативный damage-хук.
- Точки ставятся по позиции игрока (ноги + смещение по Z), а не трассировкой
  по прицелу — это специально, чтобы не тянуть зависимость `NativeTrace.gamedata.json`,
  как в оригинальном `Lazer` от ByDexterTR. Для точной расстановки просто
  подойдите вплотную к нужной точке в мире.
